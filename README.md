# IPL Analysis (2008–2025) — Power BI Dashboard

## Project Description
This project analyzes IPL cricket data from 2008 to 2025 using Python and Power BI. The dashboard helps explore team performance, player statistics, match results, and season-wise trends.

## Tools Used
- Power BI
- Python
- Pandas and NumPy
- DAX and Power Query
- Matplotlib and Seaborn

## Key Features
- Analysis of IPL teams and player performance.
- Identification of season winners, Orange Cap holders, and Purple Cap holders.
- Visualization of batting statistics, including sixes, fours, and centuries.
- Interactive charts, filters, and KPI visuals.

## Project Workflow
1. Collected and prepared the IPL dataset.
2. Cleaned and transformed data using Python and Pandas.
3. Built interactive dashboards in Power BI.
4. Visualized trends to explore team and player performance.

## Project Outcome
The dashboard provides a visual way to explore IPL statistics across seasons and compare team and player performance.
